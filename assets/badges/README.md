# Rhetoric Evaluation Badges

This folder contains badge images for the 5 rhetoric evaluation levels.

## Badge Files Required:

1. **unstructured.png** - For scores 0-4
2. **emerging-persuader.png** - For scores 4.01-8
3. **strategic.png** - For scores 8.01-12
4. **compelling.png** - For scores 12.01-16
5. **master-orator.png** - For scores 16.01-20

## Specifications:

- **Format**: PNG (with transparency support)
- **Recommended Size**: Height of 40-60px (width auto-scales)
- **Design**: Each badge should have an icon/visual that represents the level
- **Background**: Transparent or white background recommended

## Usage:

The badges automatically display in the Initial Interview Sheet based on the student's Rhetoric Evaluation total score (0-20).

## To Replace Placeholder Files:

1. Design or obtain badge images for each level
2. Save them with the exact filenames listed above
3. Replace the placeholder files in this folder
4. Badges will automatically appear when viewing the Initial Interview Sheet

## Score Thresholds:

| Level | Score Range | File Name |
|-------|-------------|-----------|
| Unstructured | 0 - 4 | unstructured.png |
| Emerging Persuader | 4.01 - 8 | emerging-persuader.png |
| Strategic | 8.01 - 12 | strategic.png |
