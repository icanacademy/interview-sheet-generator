# How to Add a Custom Icon to the Launch Command

You can give your "Launch Interview App.command" file a custom icon! Here's how:

## Method 1: Use an Image File (Easy)

1. **Find or create an icon image** (PNG, JPG, or ICO format)
   - You can use the ICAN logo from `assets/logo.png`
   - Or download an icon from the internet
   - Recommended size: 512x512 pixels or larger

2. **Open the image** in Preview app (double-click it)

3. **Copy the image:**
   - Press `⌘A` (Select All)
   - Press `⌘C` (Copy)

4. **Apply to your command file:**
   - Right-click "Launch Interview App.command"
   - Select "Get Info" (or press `⌘I`)
   - Click the small icon in the top-left corner of the info window
   - Press `⌘V` (Paste)
   - Close the info window

✅ Done! Your command file now has a custom icon!

---

## Method 2: Copy Icon from Another App

1. **Find an app** with an icon you like (e.g., Terminal, Safari, etc.)

2. **Get the app's info:**
   - Right-click the app
   - Select "Get Info"
   - Click the icon in the top-left corner
   - Press `⌘C` (Copy)

3. **Apply to your command file:**
   - Right-click "Launch Interview App.command"
   - Select "Get Info"
   - Click the small icon in the top-left corner
   - Press `⌘V` (Paste)
   - Close the info window

✅ Done!

---

## Method 3: Use the ICAN Logo (Recommended)

Since you have the ICAN logo in the `assets` folder:

1. **Open** `assets/logo.png` in Preview
2. **Press** `⌘A` then `⌘C`
3. **Right-click** "Launch Interview App.command" → Get Info
4. **Click** the small icon at the top-left
5. **Press** `⌘V`

Now your launcher has the ICAN branding! 🎓

---

## To Remove a Custom Icon

1. Right-click the file → Get Info
2. Click the icon at the top-left
3. Press `Delete` or `Backspace`
4. Close the info window

---

## Quick Tips

- The icon will persist even if you move the file
- You can copy icons between any files and folders
- .command files will also show the Terminal icon by default
- Custom icons are stored in the file's resource fork
